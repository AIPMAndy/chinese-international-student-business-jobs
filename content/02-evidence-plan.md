# 把经历变成能力证据

岗位要求、你做过的事、证明材料，是三列不同的信息。把它们逐条连接，才能知道应该补什么。

## 证据的六种身份

| 类型 | 可以证明 | 不能冒充 |
|---|---|---|
| 真实工作/实习，且可公开或获授权 | 在约束下完成任务、协作与真实结果 | 没做过的个人贡献、不可公开的客户业务 |
| 真实学校、社团、志愿项目 | 具体任务、组织协作、过程与有限结果 | 企业正式实习、商业收入或管理权限 |
| 自主公开资料研究 | 信息筛选、假设、分析、书面表达 | 接触过被研究公司内部资料或获得其认可 |
| 本册或自行设计的教学模拟 | 当前技能、计算、取舍、解释能力 | 实际雇主经历、真实客户和落地业绩 |
| 课程成绩、证书 | 对应课程表现或考试状态 | 真实工作责任、当地执业许可、就业保证 |
| 计划做但没做 | 准备方向 | 已完成能力证据 |

资料的真实性与能力强弱分别判断。真实但与你无关的公司大项目，不一定比你独立完成的小任务更能说明胜任力。证据可以不公开，但面试前必须知道能在授权范围内讲到哪里。

## 练习一：逐条对应岗位

**输入：** 一条完整 JD、三段真实经历、可合法展示的材料。

**操作：** 每条核心职责写“要求 → 曾做动作 → 文件或见证 → 本人边界 → 还缺什么”。先处理三条决定日常工作的职责，再补加分项。证据状态填“可展示、只可口述、需授权、尚未形成”，不要把保密义务误解成可以随意脱敏公开。

**输出：** 能力证据表和一页材料目录。**验收：** 别人能从结论回到原始事实；核心数字有单位、时间窗、分母、公式和出处；团队结果与本人动作分开。**错误处理：** 没有结果数据时，用可验证的交付物、质量检查和决策过程说明，不补造改善百分比。

### 填写示例：课程项目转商业分析申请（教学模拟）

| 项目 | 填写示例 |
|---|---|
| 岗位职责 | 通过数据分析解释经营变化，向业务同事给出建议 |
| 原始经历 | 一门课程要求分析一组合成订单数据；候选人负责清洗和分层分析 |
| 可展示材料 | 标注为合成的原始 CSV、数据字典、清洗规则、计算表、两页报告 |
| 能证明 | 定义转化率、处理重复记录、解释渠道结构差异、讨论归因限制 |
| 不能证明 | 在实际企业部署报表、推动收入提升、管理真实客户 |
| 需要补 | SQL 查询与同伴复算；英文五分钟汇报 |
| 验收 | 随机改一行输入后结果同步变化；被问到“为什么不能证明因果”能回答 |

## 练习二：把缺口排成行动

**输入：** 缺口列表、每周可用时间、最近一个真实申请截止日。

**操作：** 按“决定能否申请、决定能否通过评估、仅为加分”排序。每次只补一个阻塞项和一个专业证据。以四周、每周六小时为教学安排：两小时做任务，一小时核对，两小时修改，一小时讲解。你可以改时长，但不要用学习小时数代替产出。

**输出：** 每项都有交付物、完成时间、验收人和失败分支的行动表。**验收：** 行动不是“学习财务”，而是“用六行模拟损益解释销量、价格与成本变化，独立核对总差异”。**错误处理：** 一周做不完就缩小问题，不换一套工具重新开始；截止将近且缺口属硬门槛时，选择下一批次或相邻入口。

## 六条路线应该留下什么

**咨询。** 一页问题定义、假设树、两种可行方案、关键算式、建议与改变建议的条件。练习被打断后重新说明结论。

**金融与会计。** 原始数据与口径、对账、差异解释、风险与不可确定项。投融资要说明估值假设，FP&A 要解释经营与预算，核算审计要保留凭证和判断链。

**市场与品牌。** 受众证据、信息策略、创意为什么适合、预算、测试方案。效果营销区分平台归因与真实增量；品牌研究不把少量访谈当全体消费者。

**运营与供应链。** 需求假设、库存/产能/交期、服务与成本取舍、异常回退。不要只画没有执行条件的流程图。

**商业分析。** 数据字典、粒度、清洗、查询、计算、分层、建议和限制。图表是解释工具，结论能否复算更重要。

**销售与 BD。** 目标客户筛选理由、发现问题的问句、决策链与资格判断、双方明确的下一步。发出多少消息不等于合格商机，更不等于收入。

## 无当地实习：建立真实任务，而非制造经历

可以从学校职业中心发布的项目、合法课程合作、社团财务/活动、志愿组织的明确任务或自主研究开始。先确认当地对实习、志愿和远程工作的规则；“为中国公司远程做事”不自动豁免所在地规定。

**输入：** 可合法参与的机会、任务提出者、时间和授权范围。**操作：** 书面明确问题、你的责任、数据权限、交付物、验收日期和能公开什么。**输出：** 一份小任务成果与反馈记录。**验收：** 对方真实存在，任务确实发生，材料可核查；不要求对方证明没做过的职责。**错误处理：** 无法确认授权或工作资格时改做完全自主的公开数据研究，并诚实标为自主项目。

真实小项目示例：为社团预算核对收支；为活动做报名到到场漏斗；对公开年报做业务结构研究。不要声称这些等同于企业财务、完整营销实验或付费客户交付。

## 跨专业：补最短的一条证据链

技术背景转商科分析，不必把自己包装成财务专家，先展示技术如何帮助一个经营决定。文科背景转品牌，可以展示研究与表达，再补预算和测量。商科转供应链，需要把库存、交期和供需约束算清楚。每条路径都从目标 JD 开始，不能承诺“一门证书完成转行”。

## AI 可以帮到哪一步

让 AI 解释概念、生成练习、检查逻辑、扮演追问者。你自己回到原始数据复算，确认所有引用和事实。保密材料不能随意上传；先遵守雇主、学校和评估方对外部工具的规则。在线测评禁止协助时，按规则独立完成。

可用提示词：“只根据我提供的匿名 JD 与事实账本，找出三个最影响申请的证据缺口。不要补造经历。每个建议写输入、动作、产物、验收、卡住时怎么办。把假设单独列出。”

**终点检查：** 你能用五分钟讲明白自己做了什么、为什么、数字怎么算、哪些结论不成立、下一步如何验证。答不上来时继续修改证据，不急着美化封面。
