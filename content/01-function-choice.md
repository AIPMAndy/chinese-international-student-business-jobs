# 用真实岗位选职能

选岗的单位是“职能 × 地区 × 级别 × 招聘入口”。同样叫 Business Analyst，咨询公司可能要求访谈和结构化解决问题，电商公司可能要求 SQL、报表与经营决策。名字相同，不代表训练方法相同。

## 先看三个真实样本

下表是岗位研究，不是当前开放职位推荐。网页在 2026-11-13 核验；申请前重新确认岗位状态与完整条件。只转述与选岗有关的少量事实，不能据此推断同公司全部职位。

| 岗位样本 | 原始要求揭示什么 | 候选人应怎样行动 |
|---|---|---|
| McKinsey Business Analyst，15136 | 要能以事实分析问题、形成工作交付物，并用英语及办公室当地语言沟通；要求随国家或实践领域变化 | 准备访谈逻辑、数量分析和建议书；逐办公室核对语言、学历与资格，不能只凭 Analyst 名称投递 |
| Amazon 美国 Business Analyst Intern，Summer 2027，10575250 | 要求 SQL、指定毕业时间区间，页面明确本职位不提供签证担保 | 先核对毕业窗口和合法工作安排，再准备可复算的数据分析；不能把“会 Excel”当作满足 SQL 要求 |
| P&G 德国 Brand Manager Graduate Entry，R000153296 | 要求英语和德语表达；材料包括简历、成绩/学位及相关证明，求职信为可选 | 准备消费者与品牌证据、当地语言业务讲解，按原页面清单提交，不套用所有国家一页英文简历的习惯 |

来源：[RT01 McKinsey JD](https://www.mckinsey.com/careers/search-jobs/jobs/businessanalyst-15136)、[RT02 Amazon JD](https://www.amazon.jobs/en/jobs/10575250/business-analyst-intern-summer-2027)、[RT03 P&G 官方招聘页](https://pg.wd5.myworkdayjobs.com/1000/job/Brand-Manager---Graduate-Entry--m-f-d-_R000153296)。上述毕业、语言和签证条件是特定岗位条件，不代表市场比例。

## 第一步：先排除硬门槛冲突

**输入：** 毕业与在读状态、现有工作资格、地点、可开始时间、语言、目标 JD。

**操作：** 为每个岗位标记六项：工作资格；是否需要担保；毕业年份/在读要求；到岗时间与工时；明确要求的语言；法定或雇主必需资格。分别填“满足、待确认、不满足、不适用”。“待确认”绝不能被当作满足。

**输出：** 可申请、询问后决定、当前排除三份清单。申请条件很关键但表述不清时，向招聘方问一个具体问题：是否接受你这类毕业日期/工作资格，而不是泛问“我能投吗”。

**验收：** 被排除的岗位能指向一条原始要求；可申请岗位不存在被高分掩盖的法律或明确准入冲突。

**错误处理：** 不清楚证件是否允许某类工作，回到主管机构和学校核验；岗位已经关闭则保留为能力样本、停止把它计入有效岗位池；学校排名偏好若未公开，不自行编造成硬门槛。

## 第二步：把 JD 拆成工作的对象与结果

**输入：** 每方向三至五条同地区、同级别 JD。数量是研究起点；没有这么多匹配岗位时如实记录，不用相似标题凑数。

**操作：** 每条只提炼四项：分析/服务什么对象；你要完成什么动作；交出什么材料或结果；谁用它做什么决定。最后再记录工具。不要先按 Excel、Python、证书把所有岗位归为同类。

**输出：** 例如“商业分析实习：订单与渠道数据 → 清洗、分层、归因排查 → 指标表与建议 → 业务负责人决定改善哪里”。这比“商科、会 SQL、逻辑强”更接近工作。

**验收：** 不看职位名称，仍能从职责判断属于哪条路线。把核心工作讲给同学听，对方知道你每天会产出什么。

**错误处理：** JD 太空泛时，补读同团队其他职位与官方项目页；没有证据的职责标为待确认。若主要责任是技术实现、模型训练或产品路线图，则转向 AI/产品册，不能硬塞进商科。

## 第三步：比较相邻职能，而不是比较专业

| 容易混淆的方向 | 分界问题 | 证明材料的差异 |
|---|---|---|
| 战略咨询 / 审计 / 交易咨询 | 是提出经营选择、验证账证，还是支持交易判断？ | 决策逻辑 / 审计证据链 / 财务与商业尽调 |
| 投融资 / FP&A / 核算 | 是评估投资交易、解释预算，还是准确记账结账？ | 估值及风险 / 量价成本差异 / 凭证、对账与控制 |
| 品牌 / 效果营销 / 市场研究 | 是长期心智、可衡量转化，还是消费者认知证据？ | 定位与创意 / 经济账与实验 / 研究设计与样本局限 |
| 供应计划 / 采购 / 业务运营 | 是供需平衡、供应商交易，还是流程交付？ | 库存服务取舍 / 总成本与供应风险 / 质量、时效与异常 |
| 商业分析 / IT BA / 数据工程 | 是经营决策、系统需求，还是数据基础设施？ | 指标与因果边界 / 流程需求验收 / 管道与工程可靠性 |
| SDR / 客户经理 / 合作拓展 | 是发现合格机会、持续经营客户，还是达成合作机制？ | 研究与发现对话 / 续费及关系 / 合作结构、分工与价值 |

这张表是本册的工作分类法。具体职位可能跨类，最终以原始 JD 中占比最高、决定考核的职责为准。

## 第四步：用证据排序，不计算就业概率

只在已经通过硬门槛的方向之间比较。四项各用 0/1/2/3 分，但含义分别判断：任务证据为没有证据、只能解释、能独立做出、做过且能承受追问；业务表达为无法讲清、可说明部分、可独立讲解、可应对深入追问；可补足程度为计划期内不可行、依赖多项未知、基本可行、已有资源且能按期验证；工作偏好为明确排斥、尚不确定、愿意做、体验后仍愿意持续做。按以下权重形成个人优先级：任务证据 40%，业务表达 25%，技能可补足程度 20%，工作偏好 15%。权重是教学决策工具，允许修改，不是雇主算法。

“技能可补足程度”评估的是你在计划期内完成必要练习的现实程度，不是把严重短板说成潜力。工作资格和强制语言门槛仍在前一步处理，不能被加权分抵消。

**填写示例（教学模拟）：** 候选人甲为在读商科硕士，做过课程数据分析，英语能讲业务，缺少财务核算训练；具体学校与地区不设定，也不假定其具有当地工作资格。商业分析的四项分数为 2、2、2、2，排序分为 66.7/100；品牌为 1、2、2、3，分为 58.3；财务核算的硬门槛仍待确认，暂不计算排序分。选择商业分析为研究主方向，品牌为备选，同时继续核对地区门槛。这个选择反映当前证据，不是长期职业上限。

**操作：** 使用职能选择表，先写每个分数背后的材料，再填数字。没有材料就填 0 或未知。**输出：** 一个主方向、一个相邻备选、两条暂不投入的方向。**验收：** 能讲清为什么主投、为什么放弃；时间安排能支持主方向的专业练习。**错误处理：** 两方向差别很小时，各做一个限时样本，比较作品与反馈；不要靠多做人格测评代替工作体验。

## 第五步：选一条招聘入口

| 入口 | 需要核对 | 准备重点 |
|---|---|---|
| 在校实习、暑期实习 | 在读/返校要求、学校批准、日期、工作资格 | 课程与社团证据、可用时段、一个扎实工作样本 |
| Graduate / Analyst / Trainee 项目 | 毕业区间、工作年限、地点、轮岗、测评流程 | 多轮评估、动机、数理或情景题与展示 |
| 直接招聘的初级职位 | 是真实初级岗还是要求独立经验，担保与培训是否存在 | 与实际职责紧密对应的证据，避免仅背公司价值观 |
| 有经验职位 | 相关年限、行业/客户经验、责任深度 | 真实工作成果和本人贡献，不能用课程学分代替年限 |
| 回国校招/社招 | 雇主自己的应届生口径、学历材料和到岗时间 | 中文业务表达、当地行业研究、笔试/群面与材料完整性 |

## 最终一页决定

写下：“我在【地区】申请【子职能/级别】，通过【入口】。我已核实【资格条件】，还需要确认【一项未知】。我用【材料 A】证明【职责 A】，用【材料 B】证明【职责 B】。本周只补【最关键缺口】，若【明确事实】出现，就切换到【备选】。”

如果只能写“我想进大厂，商科都可以”，继续研究岗位。你不是缺一段漂亮的求职宣言，而是还没有把工作拆清楚。
