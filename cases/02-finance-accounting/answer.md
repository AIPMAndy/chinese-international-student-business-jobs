| 项目 | 预算 | 实际 | 实际减预算 |
|---|---:|---:|---:|
| 销量 | 10,000 | 11,000 | 1,000 |
| 单价 | 100 | 96 | -4 |
| 收入 | 1,000,000 | 1,056,000 | 56,000 |

| 贡献 | 400,000 | 374,000 | -26,000 |
| 固定经营费用 | 180,000 | 200,000 | 20,000 |

销量增长 10%，收入增长 5.6%；单价下降、单位成本上升及固定费用增长使 EBIT 下降 23%。这些是对给定数据的解释，不是对真实企业的判断。

## 2. EBIT 差异桥

顺序：先按预算单价与成本计算数量影响，再用实际销量计算价格和单位成本变化，最后更新固定费用与折旧。

| 因素 | 算法 | EBIT 影响 |
|---|---|---:|
| 数量 | (11,000-10,000)×(100-60) | 40,000 |
| 价格 | 11,000×(96-100) | -44,000 |
| 单位成本 | -11,000×(62-60) | -22,000 |
| 固定经营费用 | -(200,000-180,000) | -20,000 |
| 折旧 | -(20,000-20,000) | 0 |
| 合计 | 与154,000-200,000一致 | **-46,000** |

不能把全部 82,000 元成本增加都解释为采购涨价，其中包含多卖 1,000 件的成本。不能把利息增加放进 EBIT 桥；它使税前利润进一步减少 2,000 元。

## 3. 直接计算现金

经营现金流＝收款 900,000－采购付款 660,000－经营费用付款 180,000－利息付款 12,000＝**48,000 元**。

期末现金＝期初 100,000＋经营现金流 48,000－资本开支 40,000＝**108,000 元**。本题没有新增借款、还本、分红或税款。

## 4. 从利润解释现金

| 项目 | 现金桥影响 | 原因 |
|---|---:|---|
| 税前利润起点 | 142,000 | 本题税款忽略，利息计经营现金流 |
| 加回折旧 | 20,000 | 本月费用但不是本月付现 |
| 应收增加156,000 | -156,000 | 已确认收入的一部分尚未收款 |
| 存货增加48,000 | -48,000 | 采购超过当月已售产品成本 |
| 应付增加70,000 | 70,000 | 一部分采购尚未付款 |
| 应计费用增加20,000 | 20,000 | 一部分确认费用尚未付款 |
| 经营现金流 | **48,000** | 与直接法一致 |

交叉检查：

- 应收：200,000＋收入1,056,000－收款900,000＝356,000。
- 采购：已售产品成本682,000＋存货增加48,000＝730,000。
- 应付：150,000＋采购730,000－付款660,000＝220,000。
- 应计费用：40,000＋确认费用200,000－付款180,000＝60,000。

本题没有完整报表、全年季节性或客户账龄，不能凭一个月判断企业整体偿债能力，更不能把应收增加等同于坏账。

## 5. 建议备忘录示例

**主题：销量增长未带来利润增长，应同时检查定价、成本与回款。**

本月收入比预算高 5.6%，但 EBIT 比预算少 4.6 万元。增加的销量带来 4 万元贡献，未抵消价格、单位成本和费用合计 8.6 万元的不利影响。税前利润为 14.2 万元，经营现金流为 4.8 万元，主要受到应收与存货增加影响。

建议销售负责人在下周三前按客户和订单拆解折扣，检查是否由产品组合、一次性促销或合同条款造成；采购及生产负责人核对单位成本增加的报价、耗用、损耗和批量因素；财务与业务共同建立到期回款与库存清单，优先核对大额未收款和滞销项目。

本次数据只有一个产品和一个月，不能推断可持续利润、客户违约概率或全年预算。行动效果需以新期间的同口径数据复核。若新增资料证明价格下降换来长期合同价值，应比较未来贡献与风险后再决定是否调整。

## 6. 技术追问及检查答案

**为什么不直接建议涨价 4 元？** 题目没有价格弹性、竞品、合同和客户结构，恢复价格可能减少订单。可以把11,000×4＝44,000作为数量不变的机械测算，不能当作现实收益预测。

**如果应收不增加，其他项目不变？** 经营现金流会从48,000增加至204,000。但这只是反事实算术，不能认为全部应收都能立即收回。

**折旧为什么加回，资本开支又扣掉？** 利润已经扣除本期折旧，因此现金桥加回；本期实际购买设备的现金在资本开支中扣除，两者不是重复。

**本月是否可以证明预算有问题？** 只能定位偏差；需要预算假设、制定时间、业务变化和历史误差才能判断预算质量。
