# A｜FP&A 评分与复盘

这是教学评分，不是雇主选拔标准。

| 维度 | 分值 | 满分标准 |
|---|---:|---|
| 输入与口径 | 15 | 期间、币种、确认/现金、EBIT/税前利润分清 |
| 利润模型 | 25 | 关键结果正确，公式可复核，不混入利息 |
| 差异解释 | 20 | 数量/价格/成本/费用解释完整，对平 -46,000 |
| 现金与检查 | 25 | 两条路径均得48,000，期末现金108,000，余额核对正确 |
| 建议与表达 | 15 | 责任、证据、时点和局限清楚，不把测算写为事实 |
| 合计 | **100** |  |

每项按完整、部分、缺失给满分、约半分、零分并记录依据。80 分以上进入陌生题；60-79 分重做最大缺口；低于60先修口径与对账。该分档仅用于训练。

出现“用利润直接替代现金”“差异不平仍提交”“把模拟写成雇佣经历”时，先修正再用于申请。

## 复盘字段

练习日期｜目标子方向｜数据版本｜错误位置｜根因｜修正公式/口径｜复算结果｜复核人反馈｜下一次改变的输入｜真实性标签是否保留。

一次练习后只选一个主要改进点。例如下一轮将价格改成98，独立重算收入、EBIT、利润桥，同时确认没有擅自改变原案例的现金和余额数据；若要联动现金，必须另写收款假设。不能修改一个输入却留下相互矛盾的报表。
