# CSV 可编辑模板

版本 1.0，2026-11-13。七张表对应工作簿七个入口。

蓝色输入、下拉、冻结行列和排序公式在 Excel 工作簿中可用。CSV 只保留字段、样例和空白填写行，不保留格式、下拉或公式。职能选择 CSV 的排序分留空；自动计算请使用 business-job-workbook.xlsx。

岗位研究含公开招聘来源样例；其他示例为教学模拟或填写示例，均不是客户记录。使用前替换示例。保留记录性质，不把模拟写成真实工作。不要把已填写的个人求职记录提交到公开仓库。

排序分仅在硬门槛为“满足”、四项评分均为 0 至 3 且权重有效时计算。默认权重依次为 40%、25%、20%、15%，按加权分除以 3 再乘 100；结果仅用于个人排序，不是招聘概率。硬门槛待确认、不满足、评分缺失或权重合计不为100%时留空。权重在工作簿职能选择表 D10:G10 可编辑。

数字零与未知不同。日期格式为 YYYY-MM-DD；未知日期留空。申请事件按实际发生填写，不从最后结果反推中间事件。
